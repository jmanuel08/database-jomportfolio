# Module 3 — LLM-Assisted SQL & Query Profiling

## Overview

This module focuses on writing SQL queries, checking query execution plans, benchmarking indexes, and preventing SQL injection.

## Learning Goals

- Write complex SQL queries using JOIN and GROUP BY.
- Understand and read EXPLAIN QUERY PLAN.
- Compare query performance before and after adding indexes.
- Verify SQL queries generated by an LLM.
- Prevent SQL injection using bound parameters.

## Tasks Completed

### Studio Lab
- Task 1: LLM-generated SQL query and query plan
- Task 2: Index benchmarks and performance comparison
- Task 3: SQL injection demonstration using Python
- Task 4: Relational algebra and SQL verification
