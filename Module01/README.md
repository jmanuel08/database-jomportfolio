# Module 1: Introduction and Local-First Foundations

## Learning Goals

> Understand file-based storage and data flows. Understand local-first development. Learn the basics of embedded SQLite databases.

**My plan:** I want to learn how databases help engineers collect, store, and analyze real-world data to better understand machine performance and improve engineering processes.

## Module Description

In this module, I explored the fundamentals of databases, SQL, and local-first data management. I learned how to work with SQLite, use the SQLite shell, import data from CSV files, and analyze machine telemetry.

I practiced SQL queries to count readings, calculate averages, find maximum values, group data by machine, and filter readings by time. I also used `EXPLAIN QUERY PLAN` to examine how SQLite executes a query.

Furthermore, I explored Datasette to browse and filter database records and export results. I used Git and GitHub to organize my portfolio, document my work, and track changes.

These activities helped me understand how data can be stored locally, queried efficiently, checked for correctness, and used to answer practical engineering questions.

## Task Inspirations

## Task: What Is IoT?

### Domains and Included Areas

- **Industrial IoT:** Monitoring manufacturing machines and industrial processes using sensor data.
- **Smart homes and buildings:** Monitoring temperature, energy consumption, and connected equipment.
- **Predictive maintenance:** Analyzing machine readings to identify unusual behavior and support maintenance decisions.

### Commonly Used Data Protocols

- **MQTT:** A lightweight messaging protocol commonly used to exchange data between IoT devices and applications.
- **HTTP/HTTPS:** Protocols used to exchange data between devices, servers, and web applications.

### Typical Devices (Appliance or Microcontroller)

- **Sensors:** Measure physical conditions such as temperature, vibration, humidity, and pressure.
- **Microcontrollers:** Devices such as ESP32 and Arduino can collect sensor readings and communicate with other systems.
- **Industrial machines:** Equipment fitted with sensors can produce telemetry data for monitoring and analysis.

### Challenges

- **Data storage:** Storing large amounts of sensor readings in an organized and accessible format.
- **Data quality:** Checking that measurements and query results are accurate and meaningful.
- **Connectivity:** Maintaining reliable communication between IoT devices and other systems.
- **Security and privacy:** Protecting devices and data from unauthorized access.
- **Data analysis:** Turning raw sensor readings into useful information for engineering decisions.
