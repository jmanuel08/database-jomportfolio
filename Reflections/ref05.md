# Reflection 05 – Normalization vs. Denormalization

## 1. What is my take-away?

I learned the difference between normalization and denormalization. Normalization reduces repeated data, while denormalization can make reporting easier. Storage, query speed, and data updates are important when choosing a database design.

## 2. What was good?

I enjoyed creating the database and testing queries with 200,000 records. It was interesting to compare both database designs.

## 3. What was difficult?

Understanding functional dependencies, primary keys, foreign keys, and query plans was challenging for me. I also needed time to understand some SQL commands.

## 4. What was interesting?

I expected the denormalized query to be faster, but the normalized query was faster in my test. I also learned that adding an index does not always improve performance.
